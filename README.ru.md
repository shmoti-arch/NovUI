# Функции
* Создание UI элементов по типу кнопок окон и тп.
* Переключатели и кнопки с настраиваемым функционалом
* И многое другое...

# Установка
Чтобы установить библиотеку вставьте данную переменную в самом верху вашего скрипта;

```lua
local NovUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/shmoti-arch/NovUI/refs/heads/main/LIB"))()
```
